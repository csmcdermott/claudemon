# claudemon

A macOS menu bar app that monitors your [Claude Code](https://claude.ai/code) usage in real time.

Tracks tokens, cache hit rates, tasks and queries (with p50/max token distributions),
model and tool usage (skills + MCP), recent sessions, active session state, and 5h /
7d rate-limit utilization — served from a floating dashboard that lives next to your clock.

## Metrics

claudemon reads every `~/.claude/projects/**/*.jsonl` record and aggregates the
following over the selected range (12H / 7d / 30d / All / Custom). A **query** is
one user turn plus its assistant reply chain. A **task** is a contiguous span of
queries inside one session, split on a 30-minute idle gap, a `/clear`, a git
branch change, or a session boundary.

| Metric | What it is | How it's measured |
| --- | --- | --- |
| Sessions | Distinct Claude Code sessions active in the range | `COUNT(DISTINCT session_id)` over messages in range |
| Input tokens | Uncached input tokens sent to the model | Sum of `usage.input_tokens` from assistant messages |
| Output tokens | Tokens generated by the model | Sum of `usage.output_tokens` from assistant messages |
| Cache hit % | Share of input served from prompt cache | `cache_read / (input + cache_read + cache_creation)` |
| Tasks | Distinct work units in the range | `COUNT(DISTINCT task_id)` (boundaries per the rule above) |
| Queries | Distinct user turns in the range | `COUNT(DISTINCT query_id)` |
| Tok / query | Average tokens per query | `(input + output) / queries` |
| Tok / task | Average tokens per task | `(input + output) / tasks` |
| Daily tokens + cache hit % | Per-bucket stacked input / output bars with cache % overlay | Bucketed by local hour (day views) or local day; cache % per bucket |
| Tasks & queries chart | Per-bucket queries-per-task stacked bars with p50 / max tokens per task overlay | Tasks grouped by bucket; p50 = lower-median `sorted[(n-1)//2]` of per-task `input + output` sums |
| Queries by token volume | Per-bucket top-10 query token stack (others collapsed) with p50 / max overlay | Queries ranked by `input + output`; p50 / max computed across all queries in bucket |
| Model breakdown | Tokens and message count per model | `GROUP BY model` over messages in range |
| Skills used | Per-skill call count with p50 / max output tokens | Aggregated from `tool_uses` rows where `tool_type = 'skill'`; sorted by max output tokens |
| MCP tools | Per-tool call count with p50 / max output tokens | Aggregated from `tool_uses` rows where `tool_type = 'mcp'`; sorted by max output tokens |
| Recent sessions | Last 10 sessions with tokens, task and query counts | Join of `sessions` and `messages` in range, ordered by `started_at DESC` |
| 5-hour session usage % | Current rate-limit consumption for the rolling 5h window | Anthropic OAuth API (`/api/usage`), 115 s cache; fails open if unavailable |
| 7-day weekly usage % | Current rate-limit consumption for the rolling 7d window | Same source as 5h |
| Menu bar token count | Today's output tokens, live | Sum of `output_tokens` since local midnight, refreshed on every JSONL write |
| Active session dot | Whether Claude Code is mid-turn | Reads `status` field from `~/.claude/sessions/*.json` |

## Requirements

- macOS 13+
- Python 3.11–3.13 (Python 3.14 is not yet supported — the `py2app` bundler used by `just build` does not support 3.14 yet; see [py2app#553](https://github.com/ronaldoussoren/py2app/pull/553))
- [just](https://github.com/casey/just) (task runner)

## Download

Grab the latest prebuilt `.app` from the [releases page](https://github.com/csmcdermott/claudemon/releases).

Unzip and double-click to run. The first launch of an unsigned bundle requires right-click → Open to bypass Gatekeeper.

## Install from source

```bash
git clone https://github.com/csmcdermott/claudemon.git
cd claudemon
just setup          # creates .venv and installs dependencies
just install-hooks  # install pre-commit + pre-push hooks
claudemon           # launch the app
```

The menu bar icon appears and starts monitoring `~/.claude/projects/` immediately.

## Build a standalone .app bundle

```bash
just build          # builds dist/claudemon.app
just install-app    # builds and copies to /Applications/claudemon.app
just release        # builds, zips, and publishes a GitHub release
```

## Configuration

Settings live in `~/.claudemon/config.json` and are created automatically on first run.

| Key | Default | Description |
|-----|---------|-------------|
| `task_gap_minutes` | `30` | Idle time in minutes used to separate adjacent tasks |
| `section_collapse_state` | `{}` | Collapsed/expanded state for each dashboard section |
| `section_order` | `[]` | Dashboard section order set by drag-to-reorder |
